Open this folder (`vault/`) as an Obsidian vault. This note is the Map of
Content — the hub that links everything. `Cmd/Ctrl+O` to jump, `Cmd/Ctrl+G`
for the graph view.

## How to use this vault

1. Open `vault/` in Obsidian (Open folder as vault).
2. Start a note from a template: command palette → "Insert template".
3. Wikilink freely (`[[note name]]`). Backlinks build the graph.
4. Tag with `#research #design #decision #competitor` for filtering.
